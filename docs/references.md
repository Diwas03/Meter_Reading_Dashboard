# Official documentation checked

Checked 2026-11-03. Direct documentation domains were blocked by the running cloud policy, so the current content was read over verified HTTPS from the providers' official source repositories. No TLS/signature/checksum checks were disabled.

- [Supabase Edge authentication](https://supabase.com/docs/guides/functions/auth), [official current source](https://github.com/supabase/supabase/blob/master/apps/docs/content/guides/functions/auth.mdx): custom external authentication must disable the platform JWT gate and verify the credential inside the function. Provisioning explicitly verifies Auth with `getUser`; ingestion explicitly verifies gateway tokens. The newer `@supabase/server` wrapper is optional; this implementation uses the supported supabase-js API directly.
- [Supabase billing and Free quotas](https://supabase.com/docs/guides/platform/billing-on-supabase), [source](https://github.com/supabase/supabase/blob/master/apps/docs/content/guides/platform/billing-on-supabase.mdx): Free database 500MB/project, egress 5GB, Edge invocations 500k, 50k MAU; two Free projects across relevant organizations.
- [Supabase Cron](https://supabase.com/docs/guides/cron), [source](https://github.com/supabase/supabase/blob/master/apps/docs/content/guides/cron.mdx): pg_cron through Integrations → Cron or SQL, monitor job-run details, recommended maximum eight simultaneous jobs and ten-minute job duration. Our cleanup is a single bounded SQL function every ten minutes.
- [GitHub Pages limits](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits), [source](https://github.com/github/docs/blob/main/content/pages/getting-started-with-github-pages/github-pages-limits.md): personal/noncommercial use restriction, 1GB site, 100GB/month soft bandwidth, ten-minute deploy timeout; custom Actions workflows are exempt from the ten-builds/hour soft limit.
- [Arduino CLI v1.3.1 release](https://github.com/arduino/arduino-cli/releases/tag/v1.3.1): downloaded official Linux CLI and verified its SHA-256 against the published checksum list. Board/library indexes remain blocked by policy; no firmware build or hardware result is claimed.

Deployment commands and pinned Arduino packages are documented in README. Provider/account-specific settings must still be verified on the actual target project and hosted deployment.
